# Source and model notes

This package was generated for the project brief **Customer Churn Prediction with Feedback Mining**. The included demo dataset is synthetic and was programmatically generated for illustration; it is not real customer data and its apparent model performance is not evidence of real-world accuracy.

The code uses open-source packages: FastAPI, pandas, NumPy, scikit-learn, and vaderSentiment. Review their current licenses and versions before commercial deployment.

No external customer dataset is bundled. If the project is extended with a Kaggle or other third-party dataset, add the exact source URL, creator, license and any attribution required by that dataset's terms.
